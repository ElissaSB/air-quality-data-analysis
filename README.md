# Air Quality Analysis

This project explores air pollution patterns and environmental factors using the Air Quality UCI dataset.

## Tools Used

- R
- R Markdown
- ggplot2
- dplyr

## Project Objectives

- Analyze air quality measurements
- Explore relationships between pollutants
- Identify trends and patterns
- Visualize environmental indicators
